    接口通用读法
    idu_lsu_ / lsu_idu_
    前两个字段标记信号方向。pipe3 发 Load，pipe4 发 Store 地址，pipe5 发 Store 数据。
    iid / preg / *_entry
    IID 用来识别指令并比较程序年龄，PREG 标识整数物理寄存器。图中的队列标识是 12 位 one-hot，0x004 对应第 2 项，0x020 对应第 5 项。lsiq_pop_entry 可同时含两个出队位。
    sel / gateclk_sel
    sel 表示 RF 下传有效。gateclk_sel 由 RF 指令有效产生，供相关流水级开钟。
    inst_size[1:0]
    普通整数 Load 和 Store 的访存大小编码。00、01、10、11 依次为 1、2、4、8 B。
    AG / DC / DA / WB
    依次为地址生成、检查与查询、访问结果处理、写回。SD EX1 接收 Store 的写数据。
    LSIQ / SDIQ / LQ / SQ / RB
    IDU 的 LSIQ、SDIQ 保存待发射操作。LSU 的 LQ 跟踪 Load 顺序与冲突，SQ 保存 Store 地址和数据，RB 跟踪未返回的读操作。
    full[i] / not_full
    前者给 LSIQ 第 i 项置等待原因，后者是全局容量条件。当前实现的 sq_not_full 和 rb_not_full 要求至少两个空位，lq_not_full 要求至少一个。已最老的项也可解除这三类等待。
    wakeup / tlb_wakeup
    前者汇合多种重发和依赖解除反馈。后者直接来自 MMU，用于解除 TLB busy。μTLB miss 若采样到 busy 为低，LD DC 可走 wakeup 立即重试路径。
    dupN
    同一逻辑信号的多个副本，连接到不同的 IDU 消费端。图中用 dup1 跟踪 AIQ0。
    全接口波形
    覆盖 个 LSU ↔ IDU 直连端口，以及时钟、复位等公共输入。逐拍说明引用的模块内部信号也随场景一起显示。
